# SQL Murder Case — учебный проект

Разбор кейса «Murder Mystery» на SQL: поиск свидетелей, JOIN, фильтрация, сортировка, LIMIT, подзапросы.

## Цель
Отработать JOIN (INNER JOIN), WHERE + LIKE, ORDER BY + LIMIT, CTE, агрегации. Показать понятную структуру запросов для обучения и портфолио.

## Таблицы
- `person` — люди (имя, адрес)
- `north_witness` — свидетели с севера
- `interview` — протоколы допросов

## Как запустить
1. Создай базу данных (SQLite/PostgreSQL).
2. Выполни `data/schema.sql` (создание таблиц).
3. Выполни `data/insert_data.sql` (заполнение данными).
4. Запускай запросы из папки `queries/` по порядку.

## Примеры техник в проекте
- JOIN с алиасами `nw`, `i` (одинаковая структура в разных файлах).
- Фильтрация по улице и сортировка по номеру дома.
- Подзапросы и CTE для разных вариантов решения одной задачи.

## Файлы
- `data/schema.sql` — DDL (CREATE TABLE).
- `data/insert_data.sql` — DML (INSERT).
- `queries/*.sql` — запросы по шагам.
